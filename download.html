Quick Setup Guide

1. Download and extract the ZIP file

2. Install Node.js and MongoDB if not already installed

3. Run the appropriate setup script:

# Windows:
preview.bat

# Linux/Mac:
chmod +x preview.sh
./preview.sh

System Requirements

  • Node.js (v14 or higher)
  • MongoDB
  • npm or yarn package manager
  • Modern web browser
